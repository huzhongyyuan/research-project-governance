# 治理、权限与持续改进

## 三省：分离职责，而非强制审批链

| 职责 | 输出 | 边界 |
|---|---|---|
| 中书：策划 | 问题、候选主张、里程碑、任务分解 | 建议不能写成用户决定；拆任务不新增权限 |
| 门下：审查 | 有证据和位置的问题、验收意见 | 区分阻断/重要/建议；不能用偏好无限封驳 |
| 尚书：协调 | 任务与依赖、资源安排建议、总览 | 不成为第二生产 writer，不替用户扩大目标 |

小任务同一 Agent 可兼任并自检；关键论文结论、昂贵不可逆实验或最终交付需要较强独立复核。若没有独立审查者，明确写“自检/独立复核待完成”，不能冒充独立验收。能否委派由当前权限决定。

六部是可按需调用的能力：文献理论、数据工程、实验算力、评测复现、论文表达、档案交付。没有工作就不启动角色，不为组织形式制造 Session。

## 全局与项目

- 全局索引维护项目 ID、权威主机/根目录、当前目标版本、协调联系人和项目快照链接；不复制全部任务与实验记录。
- 项目负责自己的目标、代码、数据、任务、证据与验收。实验或论文可以有子工作包，近端拆细、远期保留粗粒度。
- 用户可在任意相关任务改变要求；接收者识别讨论/明确指令，登记原消息来源及受影响项。影响其他 owner 时用已授权渠道交接；未发送或未确认需标 pending，不能假定送达。
- 新消息只有在来源、时间、作用范围和明确替代关系可核实时才覆盖旧要求；冲突不按文件 mtime 或相似标题自动裁决。

## 权限与写入

### 本机与服务器分工

服务器项目默认让本机承担目标澄清、任务协调、审查和监控，尽量通过对应服务器的既有 Session 推进，不把本机变成第二个生产执行者。远端负责人执行工作、验证结果并将任务、实验、决策与交接等记录写入对应服务器的项目权威根；本机保留索引和必要摘要，存放细则见 records.md。纯本地项目仍使用本地权威根。

向现有 Session 交接已授权事项前，核对 hostId/主机、UUID、cwd、原 rollout、实际 owner、当前活动与写入范围，不按同名标题猜目标。实际监控或续接时使用可用的 `watch-codex-session`，按 owner 选择安全渠道；本节本身不授权启动 watcher、恢复任务或新建控制面。监控只读；指令须在用户允许的任务范围内，通过已核验的 owner 路由送达，不给健康任务重复注入。

分别记录已发送、原任务已接收、新活动/执行结果、服务器记录已落盘；发送成功不等于执行完成。无安全渠道、owner 冲突或主机不可达时，只记录待交接/未知并说明阻塞，不改走另起 CLI、tmux 注入、第二 writer 或本地代跑。恢复连接后先复核接收和文件状态，再决定是否补交，避免重复执行。

每项执行任务登记负责人、精确身份（需要时为 host/session UUID/cwd）、可写路径、运行资源、禁止事项、验收人/规则。资料公开可读不意味着可更改。

负责人登记不能当分布式锁。写共享文件前核实当前 writer，采用原有锁/分支/worktree/发布流程；无安全并发机制时隔离各任务输出，由指定整合者合并。禁止借治理修改 Session 数据库、抢 writer、杀 owner 或注入 tmux。

项目接入不授权恢复暂停/历史/已取消任务。现有正常任务继续；冲突只阻止新增竞争动作，是否停已有任务另按授权处理。大型计算、服务、外部发布和业务消息仍按原许可。

## 状态与验收

任务：todo → doing → review → done。独立分支 blocked、paused、cancelled；这些状态不能因心跳或“持续优化”被自动恢复。

- 自检已通过且既定规则允许自验，可从 doing 到 done；保留验证证据，不强制另开审查 Agent。
- blocked 记录阻塞、解除条件与责任；解除后按许可回到待办或进行中。
- paused 记录暂停来源；只有新的恢复授权才继续。
- done 若发现验收错误，可以明确记录原因后重开；新增改进要求通常建关联任务，不抹掉原已验收交付。
- 每项 checkbox 指向检查对象/版本/结果。任务 done 需要全部必要验收通过；“Agent 说完成”不足以打勾。
- 运行结束、技术有效性、质量验收、科学结论与交付送达分别表示。

## 有界持续优化

每轮指定：具体问题、当前基线、候选假设、最小检验、资源上限、停止条件、接受门槛。先保留已验收版本，再试新改动。

达到门槛则接纳；反例则修正或放弃；预算用完或缺权限则报告缺口。不要循环“继续优化”或只做表面措辞改动。不要求每个改进都召开会商。连续无信息增益时缩小问题、换验证路径或请求决定，不无限重试。

## 审查严重度

- blocker：继续执行会越权、破坏数据、造成生产冲突，或当前核心结论明显无效。
- major：影响主要结论或必要验收，阶段完成前须解决或明确缩小交付范围。
- minor/suggestion：不阻断无关工作；写清收益，不强制返工。

审查意见必须有具体对象、依据和可执行修复。保留意见分歧，不以 Agent 数量表决科学事实。
